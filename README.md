# C++ Engineering Projects

Documentation de projets C++ réalisés pendant ma formation. Version française suivie d'une version anglaise.

## UrbanFlow

Projet en binôme de modélisation d'un réseau de transport public à partir de fichiers CSV. Le programme prend en compte les stations, les connexions, l'affluence et les coupures temporaires afin de proposer plusieurs calculs de trajets et des outils d'analyse pour l'exploitant.

Ma contribution principale concernait le calcul des itinéraires, le menu exploitant et les fonctions d'analyse. L'optimisation d'affectation de véhicules a été intégrée en commun.

Les sources C++ finales ne sont plus présentes dans l'archive ; le dépôt ne publie donc pas de code reconstruit présenté comme original.

# English

UrbanFlow is a two-person C++ academic project modeling a public transport network from CSV datasets. My main contributions focused on route computation, the operator menu and network-analysis functions. Final C++ source files are no longer present in the archive, so no reconstructed code is presented as original source.
